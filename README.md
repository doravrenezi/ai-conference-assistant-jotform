# AI Conference Registration Assistant

A conversational conference registration prototype using FastAPI, JavaScript, SQLite, OpenAI, and Jotform.

Attendees can register, look up their registration, update details, cancel, and ask questions grounded in a conference knowledge base. Backend tools validate and perform changes after user confirmation.

This public copy uses fictional conference content and contains no attendee database or original Git history. Supply your own API keys and form ID locally.

See [setup and architecture](project_1/README.md).

## Local demo only

Use fictional attendee data. This prototype relies on a registration code and email for record access; it has no separate authentication or rate limiting. Publishing its source does not deploy a live service. Do not connect it to production registration records or expose it as a public backend without adding access controls.
