# Workshops

> Fictional demo content for this public prototype.

Each attendee must choose exactly one workshop preference during registration. Workshop preference is required even if the attendee selects only one conference day.

The valid workshop IDs are `ai_agents`, `rag_basics`, and `prompt_engineering`.

## RAG Basics (`rag_basics`)

RAG Basics is a beginner workshop on Friday, June 12, 2026 (`june_12`) from 14:00 to 15:30.

Topics include:

- Loading Markdown and JSON documents
- Chunking conference documentation
- Building a simple retriever
- Grounding answers in retrieved sources
- Returning "information unavailable" when no source supports an answer

Capacity is 100 attendees. The workshop lead is Demo Workshop Lead One.

## AI Agents (`ai_agents`)

AI Agents is an intermediate workshop on Saturday, June 13, 2026 (`june_13`) from 13:30 to 15:00.

Topics include:

- Planning and state management
- Tool-calling loops
- Validating tool arguments
- Handling failed tool calls
- Separating model decisions from backend execution

Capacity is 80 attendees. The workshop lead is Demo Workshop Lead Two.

## Prompt Engineering (`prompt_engineering`)

Prompt Engineering is a beginner workshop on Sunday, June 14, 2026 (`june_14`) from 10:45 to 12:15.

Topics include:

- Clear system instructions
- Few-shot examples
- Structured outputs
- Prompt evaluation
- Refusal and fallback wording

Capacity is 90 attendees. The workshop lead is Demo Workshop Lead Three.

## Workshop Selection Rule

The registration form accepts one workshop preference. Attendees may choose AI Agents, RAG Basics, or Prompt Engineering.
